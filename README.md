# 👨‍💻 Marcos Henrique

**`Desenvolvedor Front-end e Full Stack Júnior`**

Sou Marcos Henrique, de Minas Gerais, e desenvolvo aplicações web com **React, JavaScript, TypeScript e Node.js**. Também trabalho com **web design**, criando interfaces responsivas, landing pages e experiências visuais com animações.

Meus projetos envolvem integração com APIs, bancos de dados e desenvolvimento colaborativo. Tenho explorado também **GSAP e Three.js** para criar interações e experiências 3D na web. **Busco uma oportunidade júnior em Front-end ou Full Stack** para contribuir com uma equipe e evoluir como desenvolvedor.
